# GrandGym

Фитнес-приложение с маскотом-медведем Грэндом, тёмной темой и геймификацией.

## Статус
v0.1-alpha — каркас приложения, 5 экранов, навигация.

## Стек
- Kotlin
- Jetpack Compose
- Material 3
- Navigation Compose

## Экраны (альфа-версия)
| Экран | Описание |
|---|---|
| Онбординг | Ввод имени, кнопка ПОГНАЛИ |
| Дашборд | Приветствие, карточка готовности, кнопка НАЧАТЬ, план на сегодня |
| Тренировка | Окно видео (заглушка), таймер, карточка упражнения, ПАУЗА/ЗАВЕРШИТЬ |
| Свои | Поиск, список друзей, кнопка Добавить |
| Профиль | Аватар, шкала опыта, достижения, статистика, настройки |

## Фичи (полная версия)
- План тренировок
- Геймификация (уровни, опыт, ачивки)
- Видеоанализ техники упражнений
- Интеграция с часами (Health Connect)
- Друзья (Firebase)
